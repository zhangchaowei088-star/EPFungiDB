Platform Overview

Designed for researchers,
built around the data.

EPFungiDB integrates multi-omics data, curated genome resources, and taxonomic summaries into a unified platform. Whether you are characterizing a new isolate, investigating virulence mechanisms, or screening candidates for biocontrol applications, EPFungiDB provides structured data and searchable interfaces for your research.

The current local release connects genome assemblies, protein annotations, KEGG pathway members, BUSCO quality metrics, antiSMASH summaries, SignalP predictions, and pathogenicity-associated candidate features through the Django REST API used by this homepage.
